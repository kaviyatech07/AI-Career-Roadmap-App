# 🤝 Contributing

Thank you for your interest in contributing!

## How to Contribute

1. Fork this repository.
2. Create a new branch.
3. Make your changes.
4. Commit your changes.
5. Submit a Pull Request.

## Contribution Ideas

- Add new AI career roadmaps.
- Improve learning resources.
- Fix documentation.
- Correct grammar or formatting.
- Add diagrams and illustrations.
