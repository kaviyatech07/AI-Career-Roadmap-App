# 📈 Data Analyst Roadmap

## 🎯 Career Overview
A Data Analyst collects, cleans, analyzes, and visualizes data to help organizations make informed decisions.

---

## 🛠 Skills Required

- Excel
- SQL
- Python
- Statistics
- Power BI
- Tableau
- Pandas
- NumPy
- Data Visualization
- Communication Skills

---

## 📅 Learning Roadmap

### Step 1
- Learn Excel
- Learn SQL Basics

### Step 2
- Learn Python for Data Analysis
- Practice Pandas & NumPy

### Step 3
- Learn Statistics

### Step 4
- Learn Data Visualization
- Power BI
- Tableau

### Step 5
- Build Dashboard Projects

### Step 6
- Complete Internship

### Step 7
- Prepare for Placements

---
